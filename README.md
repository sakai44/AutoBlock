# AutoBlock 2.1.1

AutoBlock is a MeowTils extension for MeowTils 2.0.1 and Minecraft 1.8.9. It provides Predict and Timed block modes.

## Downloads

- [Built extension](AutoBlock-2.1.1.meowtils) — place it in the MeowTils extensions directory, then reload or restart MeowTils.
- [Source project](AutoBlock-2.1.1-source.zip) — includes the Java source, build files, and regression test sources. See the archive's `README.md` for build instructions and detailed behavior notes.

The extension has not been verified by the channel. Use it at your own risk. Actual server behavior still requires in-game validation.
